# Student Marks Calculator

A simple and user-friendly Student Marks Calculator developed using **Python and HTML**. This project calculates a student's total marks, average marks, grade, and pass/fail status based on the entered marks.

## 📌 Project Overview

The Student Marks Calculator is designed to make the process of calculating student academic results simple and efficient. Users can enter marks for different subjects, and the application calculates the result automatically.

## ✨ Features

* Calculate total marks
* Calculate average marks
* Determine grade
* Display pass/fail status
* Simple and easy-to-use interface
* Beginner-friendly project

## 🛠️ Technologies Used

* **Python** – For implementing the marks calculation logic
* **HTML** – For creating the user interface
* **Git & GitHub** – For version control and project hosting

## ⚙️ How It Works

1. Enter the student's marks.
2. The program calculates the total marks.
3. The average marks are calculated.
4. Based on the marks, the corresponding grade is determined.
5. The final pass/fail result is displayed.

## ▶️ How to Run the Project

### Run the Python Program

Make sure Python is installed on your system.

```bash
python student_marks.py
```

### Run the HTML Page

Open `index.html` in any web browser.
